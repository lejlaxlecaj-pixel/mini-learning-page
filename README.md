
# Mini Learning Page – Siguria në internet

Kjo faqe edukative na mëson si të mbrohemi gjatë përdorimit të internetit.

## Teknologjitë e përdorura

- HTML – për strukturën e faqes.
- CSS – për dizajnin dhe ngjyrat.
- JavaScript – për kontrollimin e përgjigjes së kuizit.
- Visual Studio Code – për shkrimin e kodit.
- Figma – për krijimin e modelit vizual.
- Git dhe GitHub – për ruajtjen dhe publikimin e kodit.
- Vercel – për publikimin e faqes në internet.

## Përdorimi i Inteligjencës Artificiale (AI)

- Mjeti i përdorur: ChatGPT.
- Për çfarë u përdor: Për shpjegime, udhëzime hap pas hapi dhe ndihmë gjatë gjetjes së gabimeve në kod.
- Çfarë mësova: Si të përdor HTML, CSS dhe JavaScript për të krijuar një faqe edukative, si dhe si ta publikoj projektin në GitHub dhe Vercel.

## Përfundim

Ky projekt më ndihmoi të mësoj bazat e zhvillimit të faqeve të internetit dhe përdorimin e mjeteve për programim dhe publikim online.
